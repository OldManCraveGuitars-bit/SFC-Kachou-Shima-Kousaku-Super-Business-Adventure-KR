# v1.11 인명·문맥 검수

## 도리우미 가쿠코 이름 정정

원문은 **鳥海赫子**이며 읽기는 **とりうみ かくこ**입니다. 종전 ‘토리우미 아키코’를 **도리우미 가쿠코**로 수정했습니다. [일본어 인물 자료](https://mangapedia.com/転生したら島耕作だった件-cags4ypnp), [출판사 작품 소개의 한자 표기](https://www.kodansha.co.jp/comic/labels/morning?page=55)를 확인했습니다. 성의 첫 음절도 일본어 표기 원칙에 맞춰 ‘도’로 통일했습니다.

대사와 선택지의 인명 표기 30개 항목, 공용 성명·성·이름 표시 세 종류, 사건 편 제목과 챕터 선택 메뉴를 갱신했습니다. 원문 한자와 게임의 호출·분기 코드는 보존했습니다.

## 다른 인물과 구분

## 함께 다듬은 문맥

- 술자리의 ‘가쿠코는 잘도 말했다’를 **‘가쿠코는 재잘댔다’**로 다듬었습니다.
- **‘그 뒤로도 가쿠코와의 관계는 이어진다’**로 빠진 조사와 연결을 복원했습니다.
- 가쓰코 장면에 말줄임표와 ‘물론’을 복원해, 다음 문장과 뜻이 잘못 이어지지 않게 했습니다.
- 후반 대사에 ‘자네 같군’을 넣어 구미코가 사랑하는 상대가 시마라는 점을 분명히 했습니다.

## 검증 범위

등록 10,419개 항목을 스캔했고 총 32개 항목을 수정했습니다. 변경 대사·선택지 31개 항목을 포함한 원판/한글 28개 완성 화면을 직접 대조했습니다. 공용 이름 표시는 ROM의 실제 호출 테이블에서도 확인했습니다.

561개 대사 루트와 150개 선택지의 화자·대기·장면·페이지 명령에 차이가 없습니다. Snes9x·bsnes로 일반 입력 23개 시나리오를 검사해 다섯 장 진입, 저장/불러오기, 세 슬롯의 다른 기록 보존, 취소를 확인했습니다. 영어 대사·글꼴과 오프닝·엔딩 그래픽도 보존했습니다.

전체 대사를 문맥별로 새로 완주하거나 모든 기기를 시험한 검사는 아닙니다. [구조화된 검수 결과](name_review_validation.json)와 [스크린샷](SCREENSHOTS.md)을 함께 제공합니다.
