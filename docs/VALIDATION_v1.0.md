# v1.0 검증 범위

현재 배포 ROM의 SHA-256을 기준으로 확인한 기록입니다. [구조화된 결과](current_validation_v1.0.json)와 [패처 EXE 검사](patcher_validation_v1.0.json)를 함께 제공합니다.

- 본편 561개·선택지 150개·오프닝 1개의 연결 본문을 재독하고, 엔딩 후기 1개 본문(5장)을 추가했습니다.
- 등록 10,419항목 중 10,411항목은 검수 승인, 8항목은 보존하는 비대사 제어입니다.
- 최신 문맥 검수에서 기존 198항목을 교정하고 엔딩 후기 5항목을 새로 등록했습니다. 이전 V0.81 이후의 수정은 누적 반영되어 있습니다.
- 본편·후기 301개 선택 항목/279개 화면과 엔딩 19개 카드의 원판·한글 네이티브 화면을 대조했습니다. 일부 항목은 같은 화면을 공유합니다.
- 원판의 화자·대기·장면·페이지 명령을 대조했습니다. 제어 효과 차이, 페이지 불일치, 등록 경계 오류는 0건입니다.
- 최종 ROM을 입력 없이 4,000프레임 실행해 오프닝·타이틀·소개문을 확인했습니다. V0.8/V0.81에서 수행한 장시간 Snes9x/bsnes·시작 버튼·리셋 검사는 과거 기록이며 이번에 모두 반복한 검사는 아닙니다.
- 후기 5장, 스태프 카드 12장, 유타카 로고, 完 화면을 대조했습니다. 영어 스태프 카드 11장은 원판과 픽셀이 같으며 完과 기존 한글화 표기도 유지했습니다.
- 실제 배포 EXE로 헤더 없는 원본, 복사기 헤더, 잘못된 해시/크기, 이미 패치된 ROM, 원본/기존 출력 보호, GUI 구성과 내장 IPS 확인 등 8개 검사를 통과했습니다. IPS 단위 검사도 12개 통과했습니다.
- 원본에 IPS를 적용하면 공개한 최종 ROM 해시와 일치합니다. ROM 자체는 배포하지 않습니다.

## 표시 확인의 한계

선택 화면은 원래 게임 코드가 장면을 그리도록 진입점만 바꾼 진단 재생을 포함합니다. 모든 일반 플레이 경로와 모든 선택 조합을 새로 완주했다는 뜻은 아닙니다. 모든 실기·휴대 기기에서 시험하지도 않았습니다.

일부 전화 장면은 진단 재생의 원판과 한글판 모두 전화기 그림이 대사 영역에 겹쳤습니다. 해당 장면은 원문 데이터·전후 문맥·보이는 부분을 대조했으며, 가려진 글자까지 완전히 표시되는 화면 검증으로 집계하지 않았습니다. 항목별 제한은 `current_validation_v1.0.json`에 기록했습니다.

공개 스크린샷 40장은 이 표시 제한이 없는 화면에서 선택했습니다. 이전 버전의 54장은 별도 역사 갤러리로 보존합니다.

## 이전 대본 도구

이 릴리스는 v1.0 패처와 IPS를 제공합니다. V0.81 릴리스의 대본 도구 EXE에는 이전 대본이 들어 있으므로 v1.0 도구로 이름만 바꿔 재배포하지 않았습니다. 일반 플레이용 패치 적용에는 대본 도구가 필요 없습니다.
