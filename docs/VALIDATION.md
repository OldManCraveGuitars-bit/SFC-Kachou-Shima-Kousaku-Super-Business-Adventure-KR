# v1.1 검증 범위

이번 버전은 v1.0에 챕터 선택 기능을 추가한 배포본입니다. [현재 결과](current_validation.json), [챕터 선택 상세 검사](chapter_select_validation.json), [패처 EXE 검사](patcher_validation.json)를 공개합니다.

- Snes9x와 bsnes에서 일반 부팅과 패드 입력만으로 다섯 장에 진입하고 초기 대사가 진행되는 것을 확인했습니다.
- Snes9x에서는 다섯 장 각각의 일반 저장을 재실행 후 불러왔고, 세 슬롯이 모두 채워진 상태에서도 슬롯별 불러오기를 확인했습니다. bsnes에서도 일반 SRAM 파일을 다시 불러왔습니다.
- DATA 1·2·3 각각을 대상으로 새 장을 시작해 나머지 두 슬롯의 기록이 바이트 단위로 보존되는지 확인했습니다.
- 취소하면 세 저장 기록이 그대로이고, 원래 불러오기 화면과 픽셀이 같은 화면으로 돌아오는지 검사했습니다. 기존 X 사운드 설정 팝업도 확인했습니다.
- 실제 패드 입력 시나리오 25개를 검증했습니다. 본문·엔딩 데이터와 원래 엔딩의 저장 삭제 코드는 v1.0과 같습니다. 변경 범위는 불러오기 연결 코드, 안내 그래픽, 추가 메뉴 코드·그래픽 및 ROM 체크섬으로 한정했습니다.
- 패처 단위 검사 12개와 실제 Windows EXE 검사 8개를 통과했습니다. 일본판 원본에 적용한 결과의 크기와 SHA-256이 공개 결과와 일치합니다.
- 신규 공개 이미지 16장은 v1.1 ROM으로 실행해 얻은 256×224 PNG입니다. 글자 덧씌우기, 보정, 확대 없이 그대로 게시했습니다.

## 이전 검수와 검증 범위

v1.0의 대사·오프닝·엔딩 교정은 그대로 포함됩니다. 이번 기능 추가를 위해 대사 전체를 다시 번역하거나 모든 분기를 끝까지 재주행하지는 않았습니다. 이전 대사 검수와 일부 전화 장면의 표시 제한은 [v1.0 검증 기록](VALIDATION_v1.0.md)에 보존했습니다.

검증은 두 에뮬레이터 코어에서 수행했습니다. 모든 실기·휴대 기기나 모든 선택 조합의 완주를 확인한 것은 아닙니다. 게임의 일반 SRAM 저장과 이전 ROM의 강제 저장 상태는 구분해야 합니다.
