# v1.11 검증 범위

[인명·문맥 검수](NAMES_AND_REVIEW.md) · [현재 검사 결과](current_validation.json) · [이름과 실행 화면 상세](name_review_validation.json) · [배포 패처 검사](patcher_validation.json)

- 등록 10,419개 항목을 스캔하고 인명 30개 항목과 별도 문맥 2개 항목을 수정했습니다. 인명 수정 항목 안의 표현 2곳도 함께 다듬어 문맥 교정은 총 4곳입니다.
- 변경된 대사·선택지 31개 항목/28개 완성 화면의 원문·한글을 직접 대조했습니다. 게임 내 공용 이름 표시 세 종류도 실제 ROM에서 확인했습니다.
- 허용한 변경은 해당 텍스트·장 제목·챕터 메뉴 그래픽과 체크섬입니다. 챕터 선택 코드는 그래픽 전송 길이 상수만 달라졌습니다. 기존 글자 배치표, 다른 그래픽, 영어 대사와 원래 엔딩 저장 삭제 동작은 보존했습니다.
- 561개 대사 루트와 150개 선택지의 화자·대기·장면·페이지 명령 차이가 0건입니다.
- Snes9x·bsnes의 일반 입력 23개 시나리오에서 다섯 장 진입, 저장/불러오기, 세 슬롯 각각의 다른 기록 보존, 취소와 화면 복귀를 확인했습니다.
- Windows 패처 단위 검사 12개와 실제 EXE 검사 8개를 통과했습니다. 일본판 원본→IPS→결과 ROM의 SHA-256이 일치합니다.
- 신규 스크린샷 16장 중 8장은 일반 부팅/패드 입력, 8장은 장면 진입 테이블만 바꾼 검증 실행입니다. 이미지마다 촬영 방식을 기록했습니다.

모든 대사의 문맥을 새로 전수 재독하거나 모든 분기·기기에서 완주한 검사는 아닙니다. 이전 검사 범위는 [v1.1](VALIDATION_v1.1.md)과 [v1.0](VALIDATION_v1.0.md)에 보존했습니다.
